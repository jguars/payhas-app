# App map (Dark)

`payhas-app-map-dark.svg` — every screen of the app, Dark theme, by flow
(sign in & setup → child app → parent → creator tools), linked with arrows,
each with a status badge and a caption of what changes next.

**Into Figma:** drag the SVG onto a Figma canvas (or File → Import). It comes
in as editable layers: screenshots as images, captions as text, arrows as
vectors. `payhas-app-map-dark.png` is a flat preview.

Built from the web build on 2026-10-30 with the test family (Aylar, Kids
lane). The Figma connector could not write it directly: the account hit the
Starter plan's MCP call limit (also on 2026-10-30).
